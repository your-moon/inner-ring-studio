# Inner Ring Studio

A database GUI over your own Postgres, MySQL, and ClickHouse (a fork of Outerbase Studio). Runs self-hosted, cloud (multi-tenant), and desktop (Electron).

## Agent skills

### Issue tracker

Issues and specs live as local markdown under `.scratch/<feature-slug>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` + `docs/adr/` at the repo root (created lazily by `/mattpocock-skills:domain-modeling`). See `docs/agents/domain.md`.
